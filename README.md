# 🐾 Pet Management System (C++)

A console-based C++ application to manage pets (dogs, cats, birds).  
Users can search, add, update, and delete pet details interactively.

## 🚀 Features
- Search pet by name  
- Add new pets  
- Update details (Color, Age, Breed)  
- Delete pet or specific details  

## 🛠 Tech Used
- C++
- STL (vector, string)

## ▶️ How to Run
g++ file.cpp -o pet  
./pet  

## 📚 Learning
- OOP concepts in C++
- Working with vectors
- Menu-driven program design
